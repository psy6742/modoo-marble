# 🎲 모두의 마블 자산 계산기

아이패드 가로 화면(1180×820, 1024×768)에 맞춘 단일 HTML 웹앱입니다.
게임이 끝났을 때 **땅값 + 현금 = 총 자산**을 바로 계산해 1~4위를 발표합니다.

## 파일

| 경로 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (HTML/CSS/JS 한 파일, 외부 라이브러리 없음) |
| `assets/apple-touch-icon.png` | 홈 화면 아이콘 180×180 RGB |
| `assets/icon-512.png` | 고해상도 아이콘 512×512 RGB (파비콘 겸용) |
| `assets/icon-v2.png` | 아이콘 원본 이미지 (재보정용) |
| `icon-preview.html` | 홈 화면 아이콘 미리보기 페이지 |
| `verify.py` / `preview.py` | Playwright 검증·미리보기 스크린샷 스크립트 |
| `research/rulebook-seoul-card.jpg` | 서울 도시증서 실물 사진 (가격 검증 근거) |

## 주요 기능

- **참여자 2~4명**: 인원 선택(좌상단), 이름 직접 입력, 실제 모두의 마블 4색
  (빨강 `#E53935` · 파랑 `#1E88E5` · 노랑 `#FBC02D` · 초록 `#43A047`).
  카드를 누르면 그 사람으로 편집 대상이 바뀌고, 모든 카드에 땅값·현금·총 자산이 실시간 표시됩니다.
- **타이머**: 기본 60분. ▶/❚❚, ↺(초기화), `-5/-1/+1/+5`분, `30/45/60/90`분 프리셋,
  직접 분 입력, 🔔 알람 테스트. 00:00이 되면 Web Audio 경광음 + 화면 경고가 뜹니다.
  타이머가 도는 동안에는 화면 꺼짐 방지(Wake Lock, 지원 기기)를 요청합니다.
- **1. 땅값**: 23개 도시(일반 18 + 관광지 5)를 보드 색 그룹으로 묶어 표시.
  - 빈 땅을 누르면 지금 선택된 참여자가 구매, 내 땅을 다시 누르면 소유 해제,
    다른 사람 땅을 누르면 인수(건물은 초기화)됩니다.
  - 내 땅은 `땅 / 빌라 / 빌딩 / 호텔 / 랜드마크` 버튼이 나타나고, 앞 단계는 자동으로 함께 켜집니다.
    랜드마크를 켜면 땅·빌라·빌딩·호텔이 모두 켜지고, 하나라도 끄면 랜드마크도 해제됩니다.
  - 관광지(독도·발리·하와이·푸켓·타히티)는 `보유(10만)` 토글.
  - 땅값 = 그 도시에 지은 모든 건설비의 합(랜드마크 포함). 관광지는 보유 시 10만.
- **2. 현금**: 참여자마다 `💵 권종별 입력` / `⌨️ 직접 금액 입력` 전환.
  - 권종: 100만 · 50만 · 10만 · 5만 · 1만 · 5천 · 1천 마블 (장수 입력, −/+ 버튼).
  - 직접 입력: 만 마블 단위 숫자 입력(소수 가능, `0.5` = 5천) + `+100/+50/+10/+5/+1/−1/−10` 버튼.
- **3. 🏆 순위 발표**: 총 자산 내림차순, 동점은 공동 순위로 표시.
  시상대·메달·팡파르·색종이 연출과 함께 땅값/현금/총 자산/도시 수/랜드마크 수를 한 표로 보여줍니다.
- **⚙️ 가격표 수정**: 도시 18곳 × 5개 항목 + 관광지 5곳 금액을 만 마블 단위로 수정.
  수정값은 기기에 저장되고, `기본값으로` 버튼으로 되돌릴 수 있습니다.
- **자동 저장**: 입력 내용은 브라우저 localStorage(`modooMarble.v1`)에 저장돼 새로고침해도 유지됩니다.
  `🔄 새 게임`은 도시·건물·현금만 지우고 이름과 가격표는 남깁니다.

## ⚠️ 가격표 정확도 (중요)

- **서울은 실물 도시증서로 확인했습니다**: 건설비용 땅 22 / 빌라 8 / 빌딩 24 / 호텔 40 / 랜드마크 40만.
  (통행료 8/16/34/70/60만, 인수 44/16/48/80/인수불가, 매각 11/4/12/20/20만 — 앱은 건설비용만 사용)
- **나머지 17개 도시는 공개 자료로 교차 확인하지 못해 기본값(추정)입니다.** 실제 카드와 다를 수 있으니
  처음 한 번 `⚙️ 가격표`에서 카드에 적힌 값으로 맞춰 주세요. 그 뒤로는 이 기기에 저장됩니다.

## 배포 / 홈 화면 추가

1. `modoo-marble` 폴더를 `psy6742/modoo-marble` 저장소로 올리고 GitHub Pages를 켭니다
   (저장소 생성은 사용자가 직접 — Pickle GitHub 앱에는 저장소 생성 권한이 없습니다).
2. 아이패드 Safari로 주소를 열고 **공유 → 홈 화면에 추가**. 아이콘과 이름
   (`모두의 마블 계산기`)이 `apple-touch-icon.png` / `apple-mobile-web-app-title`로 지정되어 있습니다.
3. 홈 화면에서 열면 주소창 없이 전체 화면으로 뜹니다(가로 고정 권장).

## 검증 결과 (Playwright)

`verify.py`로 1180×820 / 1024×768 두 크기에서 확인했습니다.

- 콘솔 오류 0건, 페이지 오류 0건, 실패한 리소스 0건
- 가로/세로 스크롤 없음(document.scrollWidth == innerWidth, scrollHeight == innerHeight)
- 서울 땅 22 + 빌라 8 + 빌딩 24 + 호텔 40 = **94만**, 랜드마크 추가 시 **134만** 일치
- 권종별 입력 2×(100+50+10+0.5)만 = 321만, 직접 입력 250 → 250만 일치
- 새로고침 후 이름·소유·현금 유지 확인
- 타이머 45분 → -5분 = 40분, 시작/일시정지, 00:00 도달 시 경고창 표시 후 끄기 확인
- 순위 발표: 1·2·3위 메달 표시, 동점(100만 vs 100만) 시 **공동 1위** 두 명 모두 표시
- 가격표 모달이 화면 안에 들어오고, 서울 땅값을 30으로 바꾸면 땅값이 102만으로 즉시 반영
